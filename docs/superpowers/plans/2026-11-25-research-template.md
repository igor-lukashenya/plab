# Research Template Implementation Plan (v2)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn plab into a GitHub template repo for R&D research: cases, notes, docs site, format-based Hyperframes media, cross-tool agent skills, CI.

**Architecture:** Port the generic parts of the reference repo (engine, theme, Makefile patterns, MkDocs), rewrite research-specific parts as placeholders, and add small stdlib-only Python scripts (tested with `unittest`) that do all file creation. Skills are thin instructions that call those scripts. Generated Hyperframes output is git-ignored.

**Tech Stack:** Make, Python 3 (stdlib; PyYAML only in `results.py`), MkDocs Material, Node 22+, Hyperframes `0.8.138`, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-25-research-template-design.md` (read it fully; this plan only names what it decides).

**Reference repo (read-only):** `REF=<reference-research-repo>`. Survey `$REF/presentation/shared/engine.py`, `$REF/presentation/talk/scripts/build.py`, `$REF/presentation/announcements.py`, `$REF/Makefile` before Tasks 5-7.

## Global Constraints

- Linux/macOS/WSL only; no Windows commands; `clean` is `rm -rf site`.
- `HF_VERSION ?= 0.8.138` defined once in the Makefile; every `hyperframes@` use goes through `$(HF_VERSION)`.
- Template runs as-is: no `{{ }}`. Sentinels: title `Research Template`, slug `research-template`.
- Slug regex `^[a-z0-9]+(-[a-z0-9]+)*$` everywhere (cases, media names, init NAME).
- Scripts are stdlib-only except `scripts/results.py` (PyYAML). All scripts expose `run(...)` for tests plus `main()` using `argparse`, and raise `SystemExit("message")` on user errors, checking everything before writing anything.
- No research-specific words in the template outside `docs/superpowers/`: `LLM|PoC|\.NET|meetup|talk|announcement|Opus|GPT|Copilot|SpecKit|ecommerce|fintech`.
- Make targets carry a `## description` comment line above them (feeds `make help`).
- **No git commits** unless the owner asks; skip commit steps. The reference repo is never modified.
- `AGENTS.md` and every `.claude/skills/<name>` are symlinks.

## Review Focus

- `make init` twice, and with a title containing `&`, `/` or `"`.
- `new-case` / `new-media` / `note` with a duplicate, an uppercase or spaced slug, or an unknown format/case: clear error, nothing written.
- `new-case` when the `# new-case:insert` marker is missing: no files created.
- `results` with no cases (writes an empty table, exit 0), with a bad `status`, and with a missing required field.
- A render with neither `CAPTIONS=1` nor `AUDIO=1` contains no caption layer and no audio track.
